# Case Study I – Student Performance Analysis

## 1. Case Study Title

**Student Performance Analysis Using Google Sheets**

## 2. Problem Statement

An engineering college stores student information, including attendance records, internal assessment scores, and semester examination marks. The college aims to evaluate students' academic achievements, recognize students who need extra academic assistance, and compare the overall performance of different departments.

## 3. Objectives

- Recognize students who demonstrate excellent academic performance.
- Find students who need additional academic guidance.
- Determine the average marks obtained by each department.
- Examine the connection between attendance and academic results.
- Present the analysis through charts and graphical representations.

- Student ID
- Student Name
